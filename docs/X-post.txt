Submitted to the @arbitrum Open House Singapore buildathon: NairaFlow.

In Nigeria, millions of people save through Ajo (Esusu). A group pays in every round, one person takes the whole pot, until everyone has had a turn. It runs on trust, and it breaks the day someone stops paying or the person holding the money disappears.

So I put Ajo on-chain, in stablecoins, where nobody holds the money.

What is in it:

> Savings circles. Every circle is its own contract. Members post a deposit when they join. Miss a round and your deposit covers the pot, so the circle carries on for everyone else. Payouts are pull based, so one bad wallet can never block a round.

> Goal vaults. Lock money until a date you pick, with an optional daily allowance. Family abroad can top it up.

> An agent that cannot run off with your money. It closes due rounds and releases allowances inside limits you set: destination, per transaction, per period, expiry. Revoke it in one click and its next attempt fails on chain with "policy inactive". Every action logs the gas price it acted at, so you can check the timing claim on the explorer.

> A savings score read straight from public events. The start of a credit record for people with no bank history.

It is live on Robinhood Chain MAINNET with Paxos' real USDG as the only token. No mock tokens. All 7 contracts are exact matches on Sourcify. It is unaudited, so please start small.

It also runs on Arbitrum Sepolia and Robinhood testnet, where I ran the whole thing with real transactions: circles that ran to the end with the agent closing every round, vault releases by the agent on its own, and a live revoke that made the agent's next call revert. The demo video is a recording of the live app doing exactly that.

Built to be checked:
23 tests, including a 128,000 call funds invariant
0 high or medium Slither findings
3 real bugs found by running it and reviewing it. One let anyone set an agent policy on someone else's vault. I fixed it, wrote tests that fail without the fix, redeployed, and left the evidence public.

=== REPLY 1 (post under the main post) ===

How the agent stays honest: it never holds your funds. Every action is checked on chain against limits you set (destination, per transaction, per period, expiry). Each one is logged with the gas price at the moment it acted, so you can verify the timing yourself on the explorer.


=== REPLY 2 ===

The bug I'm proudest of finding: PolicyManager let anyone set the FIRST agent policy on any vault, and then the real owner couldn't revoke it. No funds at risk, but it was an authorization hole. 4 of the 5 new tests failed before the fix. Full write-up in the repo: https://github.com/angelraph/nairaflow/blob/main/docs/DEPLOYMENTS.md
